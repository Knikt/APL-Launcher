# Integrate

Three files to copy, two lines in `index.html`, one line in the build list.

## 1. Copy the files

```
launcher/css/glass.css
launcher/js/glass.js
launcher/js/search.js
```

into the same paths in the repository.

## 2. `launcher/index.html`

After the launcher stylesheet:

```html
<link id="apl-css" rel="stylesheet" href="css/launcher.css">
<link rel="stylesheet" href="css/glass.css">          <!-- add -->
```

After `js/boot.js` (boot loads the rest of the modules, so these two must
come after it):

```html
<script src="js/build.js"></script>
<script src="js/boot.js"></script>
<script src="js/glass.js"></script>                   <!-- add -->
<script src="js/search.js"></script>                  <!-- add -->
```

## 3. `launcher/js/build.js`

The automatic updater loads exactly the scripts listed there, so both files
must be added to `"scripts"`, next to `js/launcher.js`:

```json
"js/launcher.js", "js/glass.js", "js/search.js", "js/preview.js"
```

`js/build.js` is generated by `tools/make-build.py`; regenerate it rather than
editing it by hand if the tool is available, and bump `"version"` so installed
screens pick the change up.

## 4. Optional: a key for Search

`search.js` exposes `APL.search.open()` / `close()` / `isOpen()`. Wire it where
the remote's keys are already handled (the `Nav` key map in
`js/navigation.js`, or the global keydown in `js/launcher.js`) if a Search key
is wanted; nothing else depends on it. The sheet is also reachable from a
Control Center tile:

```js
{ cls: "pill", icon: "globe", title: APL.t("Search"), sub: function () { return APL.t("Apps, films, shows"); },
  select: function () { close(); APL.search.open(); } }
```

The icon set has no magnifier yet; the sheet draws its own. Adding
`search: '<circle cx="10.5" cy="10.5" r="6.5"/><path d="M15.4 15.4 21 21"/>'`
to `P` in `js/icons.js` gives a Control Center tile the right glyph.

## Turning it off

`js/glass.js` adds `glass` to `<body>`. Every visual change in `glass.css` is
scoped to `body.glass`, so removing the class — or deleting the stylesheet
link — restores the translucent fills and the `backdrop-filter` dock exactly
as they are today. The search sheet keeps working either way; it just falls
back to its plain scrim.

Bodies with `perf` (the existing performance mode) never bake a backdrop: the
opaque fills stay.

## Fixed artwork

`APL.glass.setSource(url)` points the material at a fixed picture (a settings
screen, a screensaver preview) and `APL.glass.release()` goes back to the
artwork under the Home Screen. `APL.glass.src()` returns the frozen backdrop,
`APL.glass.offset(el)` its stage rectangle, `APL.glass.paint()` re-slices now.
