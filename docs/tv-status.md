## 2 November 2026: the poster layer, rebuilt

A build was signed with the same author certificate and installed in place (`install completed`), not launched, Home and startup untouched.

The backdrop had a real defect, not a timing problem: the painter tracked which of the two layers was showing with an index that moved when a swap was *requested*, while the pixels only arrived when a JPEG decode finished. Under a fast scroll a decode was superseded, the index had already moved, and the next poster faded in over a layer that had never painted - the stock wallpaper showing through. The same stale index, plus one variable holding both "what is on screen" and "what was asked for", is why a tile could keep the previous app's poster until focus left and came back. A failed fetch was also final for the session, so a request aborted by a fast row left that tile wrong for the evening.

It is now one writer. The showing layer is known by identity, the old poster stays opaque underneath until the new one has faded in, and the credit changes in the same call as the pixels. There is no generation counter, no layer index and no clear-to-wallpaper path at all: the stage can only hold an app's poster or the previous one that actually arrived. The dwell rotation uses the same fade - the slide was a second state machine over the same two layers. A failed image is retried after fifteen seconds instead of never.

Browser checks after the rebuild: 24 random moves at 40 ms gaps, then 14 polls - no mismatch; a burst of 14 moves in one task - never fewer than one visible layer, settled correct; a rotation moved Prime's poster between two of its own titles and left one layer visible once the fade ended. On the TV, the scroll itself is the owner's test.

## 3 November 2026: the voice phrase, the first-boot hitches, the held key

The microphone does not miss because of the capture path; it misses on what the set hands back. `tizen.voicecontrol` delivers the matched phrases as `VoiceControlCommand` objects, and the result array was passed straight on, where `String()` flattened it to `"[object Object]"`. A phrase the TV had recognised perfectly therefore arrived at `ask()` as noise, which from the sofa is a mic that does nothing. The words are now lifted off the command objects, and an empty result is recorded instead of being asked as a question. When a set refuses a media stream the sheet no longer stops at "the set did not allow the microphone": it arms the platform voice service and says to hold the remote's mic key. Only when neither answers does it fall back to the keyboard.

Four fixed timers in the boot path were moved onto idle slots. `getAppsInfo`, the status refresh, the control panel warm-up and the sound decode each ran at 1.4-3.5 s, which is exactly when the first posters land, so each one could steal the frame that showed them. They now wait for an idle slot, so the cold start spends its early frames painting and its quiet ones doing that work. The idle timeout still bounds the wait, so on a set that never goes quiet the work happens anyway.

A held direction key repeated at 145 ms while the dock's travel is 150 ms, so every step was restarted before the eye saw the last one land - the judder a held press produced, worst in the app drawer where every step also repaints a label. The repeat now runs at 185 ms, which lets each step finish. A single press is unchanged, because a tap never repeats.

Later that day the drawer was rebuilt around what the viewer actually watches. The shadows used to be switched off for every tile while a scroll ran and restored when it stopped, so the whole row lost its shadow and got it back - the flicker the owner reported. They are kept now and only stop being animated, which removes the per-frame re-blur without moving a single pixel of them. Every move inside the drawer takes the dock-only render path, not just a held one: opening and closing the drawer no longer pays a full pass over the capsule, panels, glass and search for a change only the dock and the app's name can show, and the rest of the screen catches up 240 ms later on the settle. Row travel came down from 260 to 210 ms, the card lift from 240 to 200, and the held-scroll travel to 135 ms.

The 185 ms pacing had no effect on the set, and the reason was the gate rather than the number: it only dropped a press when `ev.repeat` was set, and this remote's repeats arrive without that flag, so every one of them walked the row. The gate is now the clock - a second press of the same key inside the interval is a repeat, whoever says it is - and it is measured per key, so a fast change of direction still lands. That is why the pacing could be changed twice without the TV feeling any different.

Pacing moved inside the app. Rather than trusting what the remote sends, a held direction key now starts a step timer at 210 ms and a release stops it; the remote's own repeats are dropped by the time gate, so a hold can never double-step. The loop stops itself on a launch, an open sheet, an edit hold or a change of view, so a key held across a transition cannot keep walking a screen the viewer has left.

Posters are no longer held back until the row stops. A copy that has already decoded is painted mid-flick - it is a source swap on a layer that is about to cross-fade, not a decode - so the artwork changes with the row instead of snapping in once it lands; only a frame still in flight is queued for the settle. A poster that arrives mid-flick now repaints the dock alone rather than the whole screen, and the dwell rotation is no longer asked for on every repeat of a held key. The assistant's `getAppsInfo` call and voice registration moved off their 2.4 s timer onto an idle slot, and the sheet now says whether the set's voice service registered at all, so a microphone that stays silent can be told apart from one that never registered.


The assistant is gone from both packages. Its pill tool, sheet markup, keypad, canvas orb, microphone path, voice-service registration and model call were removed outright - `assistant.js`, `ai.js` and the unused `users.js` are deleted, the sheet's 66 CSS selectors and 5,991 bytes are stripped out of `style.css`, and the capsule widens to two tools, Control Centre and Home, with Search beyond them as before. That takes the WebGL orb context, the idle-keyed IPC, the 2.4 s voice registration and the whole microphone machinery off the launcher: this engine could never hand a widget the microphone, so all of it was cost with no return.

The saver is out of the paint unless it is the saver. Its element was in the stage from the first frame with only a class keeping it dark, and a start that failed half way - or a clip still winding down after `stop()` - left it visible under the dock, which is the footage the owner saw behind the apps.
