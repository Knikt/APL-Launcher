# Visuals and APIs

Logos, backgrounds and live content come from three places, in this order:

1. **The bundled catalog.** Tiles and Top Shelf backgrounds for 50+ apps ship inside the package (`launcher/images/apps/`, listed in `launcher/js/catalog.js`).
2. **Automatic artwork on the screen** (`launcher/js/autoart.js`, `launcher/js/genart.js`), for any app missing from the catalog, including apps installed later.
3. **Live Top Shelf** (`launcher/js/liveshelf.js`): what is popular right now on the selected service.

Everything is cached on the screen, so each lookup happens once.

## Bundled catalog

Generated by `tools/art/make-art.mjs` from `tools/art/apps.json`. The logos come from:
- [dashboard-icons](https://github.com/homarr-labs/dashboard-icons) (colour PNG);
- [Simple Icons](https://simpleicons.org) (brand SVG);
- [selfh.st/icons](https://github.com/selfhst/icons);
- [tv-logos](https://github.com/tv-logo/tv-logos) (French channels);
- the official icons of some projects.

Apps are matched by **name** (Samsung's app IDs differ between countries), including former names such as myCANAL, MYTF1, 6play and Max.

Each logo in `apps.json` can take these options:

| Option | Effect |
|---|---|
| `white` | recolour the logo in white |
| `knockout` | make a background colour transparent |
| `crop` | trim empty margins |
| `rotate` | rotate the logo |
| `suffix` | add a short text, e.g. the "+" of TF1+ |
| `icon` | draw a square app icon on its own gradient |

Each entry can also take these flags:

| Flag | Effect |
|---|---|
| `system` | show a Samsung app despite its system ID |
| `hide` | never show the app |
| `live` | live Top Shelf source: `trending`, `anime`, `youtube`, `youtube-music`, `games`, `gamepass`, `sports` or `dailymotion` |

Apps without live content get an abstract wallpaper in their brand colours (no logo, no text), like tvOS. With the *sheets of light* style (below), the screen draws these instead of the catalog's painted backgrounds. The `wallpapers` list in `apps.json` makes the same wallpapers for the apps described in `launcher/js/apps.js` (TizenTube, TizenBrew, Hot IPTV, Internet).

Device tiles for the Sources screen come from `tools/art/devices.json` (`--spec devices.json`).

## Automatic artwork

For apps without catalog art, `autoart.js` runs in the background after start-up, one app at a time:

| Source | Key | Provides |
|---|---|---|
| App Store search (`itunes.apple.com/search`) | none | the official 1024 px app icon and, when the app exists on Apple TV, a 1920×1080 Apple TV screenshot as background |
| TMDB watch providers (France) | TMDB | recognises streaming services (TF1+, M6+, france.tv…) for the live Top Shelf, with the provider logo as a fallback icon |

An App Store result counts only when the name matches exactly: *Overscan*, *User Guide* and *Workspace* are other apps there.

Results are kept 30 days (3 days when nothing is found). Turn this off or start a new search in *Settings › Apps*.

### Art made on the screen

Whatever is still missing, `genart.js` draws once, in a canvas, and keeps in `localStorage`:

- a 500×300 tile: the logo cut out of its plain background, on that colour;
- a background, in the style chosen in *Settings › Appearance › Top Shelf › Otherwise*.

**Sheets of light** (*Sheets of Light*, the default) are four or five sheets, each the area on one side of a smooth line across the screen, like Apple's wallpapers. A sheet is mostly its edge light: crisp at the line and fading inward, so the sheets below show through. The lines, which side each sheet fills, where its light falls and its hollows all follow from the app's ID, so an app always gets the same picture. The colours come from the app's main colour (the catalog's, or the icon's), with neighbouring hues only; a colourless brand gets graphite and silver. The light theme has tinted sheets with a soft shadow under each edge.

The picture is blurred by 10% of the width, so it is drawn at 480×270 and the screen enlarges it: about 7 KB per theme and per app. Both themes are made once; switching the theme shows the other one without drawing again. With this style, catalog apps get sheets in their catalog colour instead of their painted background, with no logo search. Real artwork (an Apple TV screenshot, live content) still comes first.

The other styles: the logo enlarged on large shapes in the app's colours (*Large Logo*, 1920×1080, about 100 KB, the catalog keeping its painted backgrounds), the colours alone, the APL wallpaper (also behind every app with *APL Wallpaper, Always*), or plain black.

The logo comes from, in order: the app's own icon if it is at least 200 px, the App Store (exact name), TMDB, dashboard-icons and selfh.st by name, the app's icon at any size. With nothing, the app's name is the logo. A small logo is enlarged at most about 3 times: small rather than blurred.

Local `file://` icons are readable in a canvas on the screen, Internet images need `crossOrigin`, and Vetro's icon address does not load there.

## Live Top Shelf

**Your own content first.** Apps can publish rows for Samsung's home with the Smart Hub Preview API (`webapis.preview.setPreviewData`): Plex its *Continue Watching* and recently added films and series, Spotify your mixes and playlists. Samsung's content service keeps them in `/opt/usr/home/owner/apps_rw/com.samsung.tv.contentservicemanager/data/.preview.db`, in its own folder, so the launcher reads them through Vetro (`sqlite3 -readonly`). When the selected app has rows there, the Top Shelf shows their first 8 pictures, re-read every 10 minutes; otherwise the sources below. The app sends its rows itself, while it runs or after it was used, also when the launcher is the home app. Plex's 240×360 posters become the 1920×1080 artwork from the same server (`/art` instead of `/thumb/…` in the transcode address), and Spotify's album covers 2000 px instead of 640. These addresses can carry the app's token: they stay on the screen and are never logged.

*Settings › Appearance › Top Shelf* sets what the Top Shelf shows, in this order: **What You're Watching** (above), **What's Popular** (the sources below), then the app's artwork, or for apps without one the style chosen in **Otherwise** (*Black* for a plain dark background). The two toggles are per profile; each one turned off is skipped. The keys' status is in *Online Services*.

| App | Content | Source | Key |
|---|---|---|---|
| Streaming services (Netflix, Prime Video, Disney+, Apple TV, Paramount+, Crunchyroll, Rakuten TV, Pluto TV, CANAL+, and services found automatically) | popular films and series in France | TMDB `discover` by watch provider | TMDB |
| TizenTube, TizenBrew, YouTube | trending videos in France | YouTube Data API v3 | YouTube |
| YouTube Music | trending music videos (Apple's Top albums without a key) | YouTube Data API v3 | YouTube |
| Music apps (Apple Music, Spotify, Deezer, Amazon Music, TIDAL, Qobuz…) | Top albums in France | Apple's RSS feed (`rss.marketingtools.apple.com`) | none |
| Xbox | Game Pass games, with their official key art | `catalog.gamepass.com` + `displaycatalog.mp.microsoft.com` | none |
| Steam Link, Moonlight, GeForce NOW, Amazon Luna, Twitch | Steam top sellers, with a screenshot | Steam store API | none |
| DAZN, beIN SPORTS, Eurosport, RMC Sport, Ligue 1+, L'Équipe | next Ligue 1 and Champions League matches | [TheSportsDB](https://www.thesportsdb.com) (free public key) | none |
| Dailymotion | trending videos in France | Dailymotion API | none |
| Plex, Jellyfin, Kodi, Emby, Stremio, Samsung TV Plus, Hot IPTV | trending films and series of the week | TMDB | TMDB |
| Websites with `live: "trending"` / `"anime"` | trending titles of the week / popular anime | TMDB | TMDB |

With a **Fanart.tv** key, textless HD backgrounds replace TMDB's when available.

For films and series, the Top Shelf shows the title and rating beside the picture. The rating is IMDb's, from [Cinemeta](https://v3-cinemeta.strem.io/meta/movie/tt0111161.json) (Stremio's public service, no key), through the IMDb ID that TMDB gives, or TMDB's own when a title has no IMDb rating yet. Results are cached for 6 hours. Pictures move slowly and stop by themselves, and they pause under the grid. A picture that fails to load is skipped.

The *Continue Watching* cards (`widgets.js`) use, like Apple TV, a TMDB picture with the title already drawn on it: TMDB tags such backdrops with a language (`/{movie|tv}/{id}/images?include_image_language=<language>,en,null`), the interface language first, then English, best rated first. Without one, the textless backdrop gets the title logo from the same call laid over it. A *Last Channel* card takes the channel's logo from [tv-logos](https://github.com/tv-logo/tv-logos) when its name matches one of the 203 French ones listed in `widgets.js` (compared without spaces, dashes or accents, `+` read as *plus*), else the IPTV provider's own logo.

Attribution: *This product uses the TMDB API but is not endorsed or certified by TMDB.*

## Keys file

`launcher/js/keys.local.js` (never committed; template in `keys.example.js`):

```js
window.APL_KEYS = {
    tmdb: "",
    youtube: "",
    fanart: "",
    webApps: [{ name: "My site", url: "https://example.com/" }]
};
```

APL Launcher Setup fills it in and keeps a copy in `%APPDATA%\APL-Launcher`.

`webApps` entries appear as apps that open in Samsung Internet. If an entry's name matches a catalog entry, it gets that entry's logo and live content.

## Regenerating artwork

```bash
cd tools/art && npm i && npx playwright install chromium
node make-art.mjs                                   # apps + catalog.js
node make-art.mjs --spec devices.json --out devices --catalog devices.js --var APL_DEVICES
python3 make-blur.py                                # blurred grid backgrounds
```

## Screen saver videos

The screen saver plays Apple's aerial videos (114 videos in 4K HEVC, with the 1080p H.264 version as a fallback) streamed from Apple's servers. `node tools/art/make-aerials.mjs` rewrites the list. They load over HTTP: `sylvan.apple.com` uses a certificate from Apple's own root, which neither the screen nor a browser trusts over HTTPS. The list comes from [OrangeJedi/Aerial](https://github.com/OrangeJedi/Aerial) and is used for personal use.
