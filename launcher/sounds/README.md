# Interface sounds

APL Launcher's own sounds, made by Knikt (Gero Corp.) in FL Studio:

- `navigate.wav`: moving from one tile to another
- `click.wav`: OK (open, confirm)
- `back.wav`: Back

They are in every package (Samsung, LG, Android TV). To use your own, replace these files with WAV files of the same names before building. Without them, the launcher plays short synthesized clicks.
